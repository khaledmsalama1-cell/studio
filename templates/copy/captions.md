# Post caption templates

## Instagram (≤ 2,200 chars; first ~125 show before "more")
```
[Hook line — restate the video's hook or a sharper version]

[1–3 short lines of value or context]

[CTA: Save / Share with someone who… / Link in bio]

[3–8 hashtags: brand core + 2–4 rotating + 1–2 niche]
```

## TikTok (≤ 4,000 chars; keep it short)
```
[One-line hook or question to drive comments] [3–5 hashtags]
```

## YouTube Shorts
- Title ≤ 60 chars, keyword first.
- Description: 1–2 lines + CTA + 2–3 hashtags.

## LinkedIn
```
[Hook line — a claim or a number]

[3–6 short lines, one idea each, white space between]

[Question to invite comments]
```
No more than 3 hashtags on LinkedIn.
