# Short-form script frameworks

Each line below ≈ one scene in content.json. `say` = spoken, `text` = on screen (≤ 7 words).

## Listicle (education) — reel, 25–35 s
1. hook — "3 things that …"
2. point 01
3. point 02
4. point 03 (best one last)
5. cta — "Save this for tomorrow."

## PAS: Problem → Agitate → Solve (promo)
1. hook — name the problem
2. point — what it costs them (agitate)
3. media — the product/solution
4. list — 3 benefits
5. stat/quote — proof
6. cta

## Myth vs fact
1. hook — "[Myth]? Wrong."
2. point — why people believe it
3. point — the fact
4. point — what to do instead
5. cta

## Before / after (transformation)
1. hook — the result
2. media — before
3. point — the one change
4. media — after
5. cta

## Story (behind the scenes / founder)
1. hook — the moment of tension
2. point — context
3. point — the turn
4. point — the lesson / what it means for the viewer
5. cta

## How-to (tutorial)
1. hook — the outcome
2..n. one step per scene (kicker = step number)
n+1. cta

## Pacing
- Reels: 2.6–3.2 spoken words/sec. 15 s ≈ 40 words, 30 s ≈ 85 words, 60 s ≈ 170 words.
- New visual every 1.5–3 s. If a `say` line is > 12 words, split it into two scenes.
